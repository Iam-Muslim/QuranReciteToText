# Quran Recite2Text — Tilawah Verification Workstation

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Space` | Play / Pause audio playback |
| `[` / `]` | Nudge selected word boundary by $\pm 10\text{ms}$ |
| `Shift + [` / `Shift + ]` | Nudge selected word boundary by $\pm 50\text{ms}$ |
| `Ctrl + Z` | Undo last boundary adjustment or edit |
| `Ctrl + Y` | Redo last boundary adjustment |
| `Tab` | Jump to next flagged confidence issue |
| `M` | Mute / Unmute audio |
| `Right Click` | Open Word Action Menu (Split, Merge, Nudge, Edit, Delete) |
